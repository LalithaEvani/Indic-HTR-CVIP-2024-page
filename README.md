# Enhancing Accuracy in Indic Handwritten Text Recognition — Project Page

Project page for the CVIP 2024 paper *"Enhancing Accuracy in Indic Handwritten
Text Recognition"* (Evani Lalitha, Ajoy Mondal, C. V. Jawahar — CVIT, IIIT
Hyderabad).

- **Live page:** https://LalithaEvani.github.io/Indic-HTR-CVIP-2024-page/
- **Paper:** https://link.springer.com/chapter/10.1007/978-3-031-93688-3_17
- **Code:** https://github.com/LalithaEvani/Indic-HTR-CVIP-2024

## Editing

Everything is in `index.html` — no build step. Figures are in
`static/images/`, pulled directly from the published paper.

## Deploying changes

```
git add -A && git commit -m "..." && git push
```
GitHub Pages serves straight from `main` — no separate build/deploy workflow.
